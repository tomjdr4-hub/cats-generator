Générateur de personnage – CATS! La Mascarade

Créez, vérifiez et exportez votre fiche de personnage (JSON importable dans Foundry VTT).

Projet fan-made non officiel, basé sur le jeu CATS! La Mascarade (Black Book Éditions, auteur Vincent Mathieu). Aucun texte du livre n'est reproduit ici : seules les mécaniques (noms, formules, coûts) sont modélisées. Voir le README pour le détail des données à compléter.
